# This folder moved

The marketing site (Vite + React) is now at **`apps/web`**.

From the **repository root**:

```bash
npm run web
```

or (same thing):

```bash
npm run dev
```

Or from this repo’s root, change directory:

```bash
cd apps/web
npm run dev
```

Then open **http://localhost:5173/**.

The admin app is separate: **`apps/admin`** (`npm run admin` from root).
