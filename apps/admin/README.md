# Tara, Cavite! Admin Dashboard

A modern, nature-inspired web admin dashboard for the Tara, Cavite! tourism platform.

## Design
- **Primary**: Olive green / Sage (#6B8E23)
- **Background**: Soft light gray (#F5F6F7)
- **Cards**: White with soft shadow, 18px border radius
- **Font**: Inter (clean sans-serif)

## Run locally
```bash
cd admin
npm install
npm run dev
```
Open http://localhost:3001

## Features
- **Dashboard**: Stats cards, map preview, recent activity
- **Tourist Spots**: Table with Add New Spot modal, search, filters
- **Routes**: Card list with Edit/View actions
- **Users**: User cards with role badges, status toggle
- **Analytics**: Line chart, bar chart, pie chart, date filter
- **Settings**: General settings, notification toggles, display options

## Functional interactions
- Sidebar navigation (click to switch pages)
- Add New Spot modal (opens, Save shows toast, closes)
- User status toggle
- Settings toggles
- Profile dropdown
- Collapsible sidebar (tablet/desktop)
